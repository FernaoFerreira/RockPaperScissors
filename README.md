# Jogo de Pedra, Papel, Tesoura

Um jogo clássico de Pedra, Papel e Tesoura, desenvolvido para praticar e consolidar conceitos de **lógica de programação** e manipulação do **DOM (Document Object Model)**.

## 💻 Tecnologias Utilizadas
- **HTML:** Estrutura da página.
- **CSS:** Estilização da interface.
- **JavaScript:** Lógica do jogo e interação com o usuário.

## ✨ Funcionalidades
- Lógica completa do jogo, com regras de vitória e derrota.
- Placar que atualiza em tempo real.
- Design responsivo para se adaptar a diferentes tamanhos de tela.

## 🧠 O que eu aprendi
- **Lógica de Programação:** Aprimorei o uso de estruturas condicionais (`if/else`) para determinar o vencedor e `loops` para gerenciar as rodadas.
- **Manipulação do DOM:** Ganhei experiência em selecionar elementos HTML e modificar seu conteúdo e estilo com JavaScript, criando uma experiência interativa.
- **Eventos:** Pratiquei a utilização de `event listeners` para capturar os cliques do usuário e iniciar a lógica do jogo.
